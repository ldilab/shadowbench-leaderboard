# ShadowBench-178 leaderboard data (by difficulty and by area)

Generated by `scripts/build_leaderboard_category_results.py`. Every method in the paper's main table
(`tables/main_results.tex`, 27 rows) scored per task on the same 178 problems, then aggregated by
difficulty level, by mathematical area, and overall.

## Files

| file | shape | use |
|---|---|---|
| `leaderboard_178_long.csv` | one row per (method, split) | direct leaderboard ingest. `split_type` is `all`, `level` or `category`; `split` is `all`, `L1`/`L2`/`L3`, or the area name |
| `method_results_178.json` | one object per method, nested `average` / `L1` / `L2` / `L3` / `categories[]` | same numbers, nested |
| `per_task_178.csv` | one row per (method, task), 27 x 178 rows | recompute any other split (e.g. level x area) |

Percentages are rounded to one decimal, over the fixed denominator `n`. `n_present` (`nPresent` in the
JSON) is how many of those `n` tasks have a source record for the method; the rest are scored 0. For the
8 agentic rows the source carries every task, so `n_present` = `n`, even though `algebra/L2/alg_gen_L2_006`
is reported by no leaderboard table for any agentic system and is scored as a failure for all 8.

## Methods (groups)

- **Agentic** (8): Claude Code (Opus 4.6 / Opus 4.8 / Qwen3 235B) and Codex (GPT-5.4), each with and
  without Numina-Lean-Agent. `agent` = `Numina-Lean-Agent` marks the + Numina rows.
- **Closed-source** (8) and **Open-source** (8): direct prompting, temperature 0; 2048 output tokens on the
  135 core, 8192 on the 44 expansion.
- **Lean-specialized** (3): Kimina 7B->8B, Goedel 8B->32B, Goedel 8B->8B (two-stage).

## Metrics

Per task, with `c` = standalone Lean compile passed (lenient gate: linter warnings allowed, real errors fail):

- `compile` = c
- `sa_pass_soft` (paper: relaxed) = c * (0.5 * forward pass rate + 0.5 * backward pass rate); a direction
  with no hidden checker counts as passed
- `sa_pass` (paper: strict) = c AND every forward and backward hidden checker passed

Aggregates are means of these per-task values, in percent.

## Difficulty levels

Display levels are the paper's L1 / L2 / L3. The benchmark records them as L2 / L3 / L4
(`record_level` column). Mapping: L1 = record L2, L2 = record L3, L3 = record L4.

## Problem set: 178 = ShadowBench-179 minus one withdrawn problem

`topology/L2/top_gen_L2_013` (display L1, core 135) was withdrawn after an error was found in its reference statement.
All 178 problems are scored for every method; a problem a method never produced output for counts
as a failure (denominator fixed).

Task ids are normalised to a lowercase area prefix (`Topology/L2/top_gen_L2_001` -> `topology/...`).
